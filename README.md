# Entrevista: IA generativa e trabalho docente (5º ano, Campo Verde-MT)

Página pública do roteiro de entrevista da pesquisa de mestrado de Rigoberto Ximenes Lopes, no Programa de Pós-Graduação em Ensino (PPGEn) em ampla associação entre o IFMT e a UNIC. Orientação: Prof.ª Dr.ª Edione Teixeira de Carvalho.

O acesso à entrevista é protegido por senha, informada pelo pesquisador aos professores convidados.

As respostas são enviadas por e-mail ao pesquisador (uma mensagem por participante) por meio do serviço FormSubmit.

Este repositório existe apenas para hospedar a página no GitHub Pages.
